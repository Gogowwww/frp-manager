# Code de conduite

[English](CODE_OF_CONDUCT.md) · **Français**

Ce projet suit le
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
En bref : soyez bienveillant et patient, surtout avec les personnes qui
découvrent frp ou l'auto-hébergement ; critiquez les idées, pas les
personnes ; pas de harcèlement, d'insultes ni de publication d'informations
privées d'autrui (adresse, adresse IP, données de configuration).

Signalez un comportement inacceptable en privé au mainteneur
([@Gogowwww](https://github.com/Gogowwww)) par le formulaire de signalement
privé (onglet **Security**, voir [SECURITY.fr.md](SECURITY.fr.md)), en
précisant qu'il concerne le code de conduite. Selon la gravité, le mainteneur
peut demander de corriger un message, retirer un contenu, donner un
avertissement ou exclure quelqu'un du projet.
