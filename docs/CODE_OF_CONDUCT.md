# Code of conduct

**English** · [Français](CODE_OF_CONDUCT.fr.md)

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and patient, especially with newcomers to frp or
self-hosting; criticize ideas, not people; no harassment, insults or
publishing other people's private information (address, IP address,
configuration data).

Report unacceptable behavior privately to the maintainer
([@Gogowwww](https://github.com/Gogowwww)) through the private reporting form
(**Security** tab, see [SECURITY.md](SECURITY.md)), stating that it concerns
the code of conduct. Depending on the severity, the maintainer may ask for a
message to be corrected, remove content, give a warning, or exclude someone
from the project.
